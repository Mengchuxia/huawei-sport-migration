# 隐私与安全边界

运动记录属于敏感个人信息（位置轨迹、心率、作息）。这个包的设计前提是：
**数据只在你的本机和你的华为账号之间流动。**

## 数据流向

| 环节 | 位置 | 说明 |
|---|---|---|
| 读取导出文件 | 本机 | 只读，不上传 |
| 生成 FIT | 本机 | 输出到本地目录 |
| 导入 | 你的浏览器 → 华为导入页 | 走华为官方页面，没有中间服务器 |
| 核验 | 你的浏览器 → 华为接口 | 与页面本身使用的接口相同 |

包内没有任何上报、统计、云端存储逻辑。

## 凭据

- 不读取、不保存账号密码、短信验证码
- 登录在真实浏览器窗口里手动完成，登录态由浏览器自己保存在
  `~/.huawei-sport-migration/browser-profile/`
- 登录令牌只存在于页面的 `sessionStorage`，脚本通过页面上下文临时使用，不落盘
- 换账号或共用电脑时：删除上面的配置目录即可彻底退出

## 浏览器配置目录

```
~/.huawei-sport-migration/browser-profile/
```

这是完整的浏览器用户数据（含 Cookie）。不要把它提交到 Git、不要发给别人。
`~/.huawei-sport-migration/upload-state.json` 只记录已上传的文件名，不含健康数据。

## 开源仓库

`assets/` 里的示例数据是合成的，不对应任何真人。提交 issue 或分享日志前，
检查是否包含：真实轨迹坐标、心率曲线、姓名、账号、登录令牌。

## 使用边界

- 只操作你自己的账号和你自己的数据
- 只走官方导入页，不绕过任何风控；遇到验证码就停下来手动处理
- 不批量注册、不代他人导入
- 不修改或删除华为端已有记录（本包没有删除能力）；用探针测类型会留下真实记录，测完请自行在 App 删除

## 速率

- 单批 ≤ 50 个文件，脚本默认 10 个一批
- 批次之间默认间隔 2.5 秒
- 出现「操作过于频繁」立即停止，等一段时间再继续
